# 双透镜骨架

总字数 2000-2500。地理章和历史章各占约三分之一，合一章是全文落点，不可省。

| 模块 | 字数 | 要求 |
|---|---|---|
| 一句话记住 | ≤ 20 字 | 金句，含比喻 |
| 🔥 这周发生了什么 | 150-250 | 热点摘要 + 为什么值得用两个透镜看 |
| 📍 地理透镜 | 600-800 | 地理速写 + ASCII 周边关系图 + 地缘人设 |
| 🏛️ 历史透镜 | 600-800 | 先例定义 + 起因/进程/结局 + 当年的关键洞察 |
| 🔭 两镜合一 | 300-400 | 地理解释"为什么在这里"，历史解释"上次怎么收场"，推演 2-3 个观察点 |
| 💡 谈资速记 | 3 条 | 地理 1 条、历史 1 条、类比 1 条 |
| 🎭 冷知识 · 📚 延伸 | 100-200 | 可精简 |

```markdown
# 🔭 {热点简称}：{地理对象} × {历史先例}

> 💡 一句话记住：{≤20 字}

## 🔥 这周发生了什么
{热点摘要：谁、在哪、做了什么、为什么全球在看} {一句话点出：地理上它为什么绕不开，历史上它像哪一幕}

## 📍 地理透镜：{地理对象}
**地理速写**：{位置、邻海邻国、影响命运的自然条件、体量类比}

**周边关系图**
{ASCII 图，emoji 国旗 + 箭头，必须带图例}
图例：⚔️ 冲突/敌对  🤝 盟友  💰 经济依存  🔥 争议地区  🛡️ 保护/控制  ❓ 复杂暧昧

**地缘人设**：{一个形象比喻} {夹在谁之间、争夺什么} {谁能拧它的阀门、代价是什么} {哪些历史包袱塑造了今天}

## 🏛️ 历史透镜：{历史先例}
**一句话定义**：{本质 + 时间跨度 + 核心意义}

**起因**：{时代背景 + 直接导火索 + 深层原因}
**进程**：{2-3 个阶段，各一两句，标出转折点}
**结局与遗产**：{即时后果 + 长期影响 + 留给今天的制度或教训}

> **当年的关键洞察**：{一句话点出最核心的因果逻辑}

## 🔭 两镜合一
**为什么总在这里**：{用地理章的结论解释热点的必然性}
**上次怎么收场**：{用历史章的结局对照这次，指出相同与不同}
**这次值得盯什么**：
1. {可验证的观察点：如果 X 发生，说明剧本走向 A}
2. {…}
3. {…}

## 💡 谈资速记
> 💡 **地理**：{≤30 字}
> 💡 **历史**：{≤30 字}
> 💡 **类比**：{≤30 字，把两者连起来}

## 🎭 冷知识
{1-2 个非 cliché 的饭局谈资，不要首都/官方语言类百科信息}

## 📚 延伸
- 📖 {书} - {一句话理由}
- 🎬 {纪录片/电影} - {一句话理由}
- 🗺️ 维基百科: [{地理对象}](优先搜索得到的真实 URL；拿不到则给搜索关键词) · [{历史先例}](同上)
```

## ASCII 关系图规范

emoji 国旗表示国家，箭头表示关系方向，符号表示关系性质，必须带图例。

国家型（乌克兰）：
```
              🇷🇺 俄罗斯
                  ↓ ⚔️
      🇵🇱 ← 🤝 → 🇺🇦 乌克兰 ← 🤝 → 🇷🇴
                  ↓ 💰
              🇲🇩 摩尔多瓦
```

通道型（马六甲海峡）：
```
              🇨🇳 中国
              ↓ 💰 (80% 石油经此)
🇮🇳 印度 ← → 🚢 马六甲海峡 ← → 🇯🇵 日本
              ↓ 🛡️
          🇸🇬 新加坡 + 🇲🇾 马来西亚
```

## 金句示例

| 类型 | 金句 | 结构 |
|---|---|---|
| 一句话记住 | 全球油罐的「唯一龙头」，伊朗手里的「随时能拧」 | 功能 + 谁掌控 |
| 地理 | 马六甲能绕，霍尔木兹几乎不能 | 对比 + 反差 |
| 历史 | 1973 年供应只减 7%，价格涨了 3 倍——稀缺是政治造的 | 反直觉数字 + 论断 |
| 类比 | 每一次「石油武器」都在给自己制造替代品 | 历史规律迁移到当下 |
