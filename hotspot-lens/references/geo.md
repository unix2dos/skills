# geo 模式：地缘人设

## 定位

地理是理解国际新闻的底层操作系统。每个国家/区域/通道都有其地缘"人设"——理解它，就能预判新闻。重点讲"关系"和"为什么"，不讲百科式的"是什么"。总字数 1000-1500。

## 选题标准（至少满足两项）

| 标准 | 定义 | 示例 |
|---|---|---|
| 新闻热点 | 近 3 个月国际新闻频繁出现 | 加沙、红海危机、台海 |
| 地缘关键 | 战略位置重要或资源/通道价值高 | 霍尔木兹海峡、苏伊士运河 |
| 被误解 | 大众认知与实际有偏差 | 伊朗不是阿拉伯国家 |
| 与中国相关 | 一带一路、贸易、地缘博弈 | 巴基斯坦、斯里兰卡 |
| 冷门但重要 | 很少被讨论但影响深远 | 吉布提、格鲁吉亚 |

热点到主题的映射示例：红海袭击→曼德海峡/也门；俄乌→黑海/克里米亚；中美→台海/南海/东盟；欧盟政治→东欧/巴尔干。

## 骨架（严格遵守）

| 模块 | 字数 | 优先级 |
|---|---|---|
| 地理速写 | 150-200 | 可精简 |
| 周边关系图 | — | 必须有 |
| 地缘人设 | 300-400 | **核心** |
| 新闻关联 | 200-300 | **核心** |
| 人文冷知识 | 100-150 | 可精简 |
| 延伸推荐 | 50-100 | 可精简 |

```markdown
# 🌍 {国家/区域/专题}

> 💡 一句话记住：{≤20 字，身份/定位 + 核心特征，含比喻}

## 📍 地理速写
{位置：洲、邻海、邻国} {地形气候：影响命运的自然条件} {体量：面积人口，用类比让人有感知}

## 🗺️ 周边关系图
{ASCII 图，emoji 国旗 + 箭头，必须带图例}
图例：⚔️ 冲突/敌对  🤝 盟友  💰 经济依存  🔥 争议地区  🛡️ 保护/控制  ❓ 复杂暧昧

## ⚔️ 地缘人设
{一个形象比喻概括"人设"} {为什么总上新闻} {夹在谁之间、争夺什么} {哪些历史包袱塑造了今天}

## 🔥 新闻关联
{近 5 年 1-2 个真实事件，用上面的地缘逻辑解读为什么会发生}

## 🎭 人文冷知识
{1-2 个非 cliché 的饭局谈资；不要首都/官方语言类百科信息}

## 📚 延伸推荐
- 📖 {书} - {一句话理由}
- 🎬 {纪录片/电影} - {一句话理由}
- 🎧 {播客} - {一句话理由}

## 🗺️ 地图资源
- 📍 维基百科: [词条](搜索得到的真实 URL；拿不到则给搜索关键词)
- 🌐 Google Maps: https://www.google.com/maps/place/{地名英文}
```

## 金句示例

| 主题 | 金句 | 结构 |
|---|---|---|
| 土耳其 | 欧亚十字路口的「两面派」玩家 | 位置 + 行为特征 |
| 马六甲 | 全球贸易的「咽喉」，中国能源的「命门」 | 功能 + 利害关系 |
| 乌克兰 | 大国掰手腕的「缓冲区」 | 地缘角色 + 形象化 |

## 示例节选：土耳其·地缘人设

土耳其是全球最会「左右逢源」的国家之一。**身份困境**：北约成员国却买俄罗斯 S-400；想入欧盟 30 年未果，转头搞泛突厥主义拉拢中亚。**战略筹码**：卡着博斯普鲁斯海峡能掐俄罗斯黑海舰队；北约第二大陆军；手握 400 万叙利亚难民，随时能给欧盟「开闸」。**历史包袱**：奥斯曼荣光让它始终有大国梦，凯末尔世俗化让它有别于中东邻居，埃尔多安时代又在往保守回摆。

新闻关联：2022 年它是少数能同时和俄乌对话的国家（黑海粮食协议在伊斯坦布尔签）；2023 年拖一年多才放瑞典入北约，要价是库尔德人和 F-16——「我虽然是盟友，但你得给好处」。
