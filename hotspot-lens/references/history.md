# history 模式：历史大事件框架速览

## 定位

| 维度 | 定位 |
|---|---|
| 事件粒度 | 宏观大事件或进程，非个人事件或单点事件 |
| 分析深度 | 框架概览（起因→进程→结果→影响），像教科书章节 |
| 输出目的 | 认知框架 + 社交谈资，非学术深挖 |
| 字数 | 1500-2500 字 |

## 选题标准（至少满足两项）

- 与近期热点有地域 / 类型 / 结构 / 主体关联
- 宏观：改变了权力格局、生产方式或观念体系
- 可迁移：能提炼出 2-3 个用于理解当下的认知模型
- 多样性：与最近 2 条不同时期、不同地域

## 选题池（参考，鼓励跳出）

| 类型 | 示例 |
|---|---|
| 战争与冲突 | 二战、冷战、十字军东征、太平洋战争 |
| 革命与变革 | 法国大革命、工业革命、俄国革命、明治维新 |
| 帝国兴衰 | 罗马帝国、蒙古帝国、大英帝国、奥斯曼帝国 |
| 思想运动 | 文艺复兴、启蒙运动、宗教改革、五四运动 |
| 经济变迁 | 大萧条、布雷顿森林体系、石油危机、全球化浪潮 |
| 科技浪潮 | 航海大发现、太空竞赛、互联网革命、AI 革命 |
| 制度演变 | 民主制度演进、联合国建立、欧盟一体化 |

时期轮换：古代（-476）/ 中世纪（476-1453）/ 近代早期（1453-1789）/ 近代（1789-1914）/ 现代（1914-1991）/ 当代（1991-）。
地域轮换：中国与东亚 / 欧洲 / 美洲 / 中东与西亚 / 南亚与东南亚 / 非洲 / 全球性事件。

## 骨架（严格遵守）

```markdown
# {事件名称}：框架速览

## 1. 一句话定义
{本质 + 时间跨度 + 核心意义}

## 2. 背景与起因
**时代背景**：{宏观环境、权力格局、社会状态}
**直接导火索**：{具体触发点}
**深层原因**：{结构性矛盾、长期积累的问题}
> **关键洞察**：{一句话点出最核心的因果逻辑}

## 3. 关键进程
**阶段一：{名称}（时间段）** {主要事件和转折}
**阶段二：{名称}（时间段）** {主要事件和转折}
**阶段三：{名称}（时间段）** {主要事件和转折}
> **转折点**：{最关键的 1-2 个转折点及其意义}

## 4. 结果与影响
**即时后果**：{短期结果}
**长期影响**：{对后世数十年/百年的影响}
**遗产**：{留给今天的制度、观念或教训}

## 5. 认知框架
**这段历史教会我们什么？** {2-3 个可迁移的认知模型}
**如何用它理解当下？** {连接触发本篇的热点}

## 6. 谈资速记
> 💡 **金句1**：{总结性论断，概括事件本质}
> 💡 **金句2**：{反直觉事实或有趣细节}
> 💡 **金句3**：{连接当下的历史类比}
```

## 示例节选：工业革命

> **关键洞察**：工业革命不是技术的突然爆发，而是制度、资本、资源、市场四要素同时成熟的结果。

> **转折点**：1830 年利物浦-曼彻斯特铁路开通——**铁路不仅运输货物，更运输了工业革命的思想和模式**。

**认知框架**：四要素模型（技术突破需制度、资本、资源、市场同时成熟）；先发优势与路径依赖；技术革命的社会成本。

**谈资速记**：
- 工业革命的本质是"机器取代手工、工厂取代作坊、城市取代乡村"。
- 1830 年铁路开通时有人担心"人体无法承受 30 公里时速"——每次技术革命都有类似恐慌。
- 英国率先工业化不是因为更聪明，而是发明创新能在那里赚到钱——制度比聪明更重要。
