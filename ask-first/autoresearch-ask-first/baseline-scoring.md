# Baseline Scoring Detail — Experiment 0

## 评分方法说明

**Turn-1 可观测评分法**：每个 subagent 产出的是**第 1 轮回复**（用户尚未作答）。因此：

- **EVAL 1（触发判断）** 和 **EVAL 2/3（发散与提问质量）**：在第 1 轮就可评估
- **EVAL 4（意图回放）** 和 **EVAL 5（强制移交）**：逻辑上要等用户多轮对话后才会出现，在第 1 轮不可评估 → 标记 N/A，**不计入分母**

每个 case 的实际分母 = 可观测 eval 数。

## 关键发现

### 🟢 做得好的地方

1. **触发判定 5/5 全中**——包括易漏档 B1（V1.1 新加的"动作形容词化"规则立竿见影）和正例沉默 E1
2. **三方向互斥性在 B1/C1/D1 全部通过**——"放弃了什么"这条强制规则起作用了，三个方向都写出真损失
3. **具体候选项规则被严格遵守**——没有出现开放题或形容词题

### 🔴 唯一失败点：A1（极端模糊输入）

**问题**：当输入完全没有对象（"优化一下"），Agent 无法做三方向发散，只能先问对象，这违反了 SKILL.md 第 2 步"无论快慢车道都要做这一步"的规则。

**根因**：SKILL.md 没描述"对象完全缺失时"的退化处理路径。

**候选修复方向（留待 experiment 1）**：
- 方向 α：在第 2 步加一个"**Step 2a：对象锚定**"——若输入连对象都没有，先用一个最小问题问对象，再进第 2 步正式发散
- 方向 β：改第 2 步的表述为"无论快慢车道，**只要对象明确**就做这一步；对象不明就先锚定对象"
- 方向 γ：修改触发规则，将"对象缺失"从第 1 步显式区分出来，走独立子流程
