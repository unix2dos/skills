# Case B：借势型（弱参考 + 商业动机回避）

## 用户初始输入
> 「我想做个像 ChatGPT 那样的产品」

## 真实缄默
不是真想做"另一个 ChatGPT"。真要的是「**做一个有人用、能赚点钱、证明我能独立做出东西**」——LLM 只是借势的载体。会回避谈钱和动机，AI 直接问"为什么"会答"觉得有意思、想学习"。

## ❌ 旧 skill 怎么栽
```
AI: 弱参考识别 ✅，三方向 — 垂直 Copilot / 通用 / Agent。选？
用户: A 垂直，技术栈用 Next.js + Vercel AI SDK 行不行？
AI: 技术栈先放放。垂直里你最有手感的是哪个领域？
用户: 我看 X 上有人做 AI 简历优化器，听说能赚钱，我也想做个类似的。
        ↑↑↑ 整段对话唯一的真信号 ↑↑↑
AI: 好，AI 简历优化器方向。目标用户、输入格式、产出形式问完？
→ 意图回放：「跳槽中级 + PDF + Web 简历优化器」
→ 三个月后没人付费，用户崩盘
```

弱参考识别 ✅ 但接不住商业动机信号。三要素齐全后**直接移交**——把"参数清晰"误当"缄默被挖"。

## ✅ 新 skill 怎么走
1. **识别借势型**：产品类比"像 X" → 处境前置
2. **不接"想学习"**："那是事后合理化。最近一周哪个时刻你在刷手机，突然冒出'我也想做一个'？"
3. **接住"X 上有人能赚钱"**："停一下。这是借势不是痛点。"
4. **World Model 三问，反例项往动机层挖**：
   - 痛点：自己最近一次写简历的不爽点？→ 用户："我不是用户"
   - 理想：打开后台看到什么最爽？→ "收入数字 + 有人 @ 我"
   - 反例：最不想做出来的版本？→ "没人用、爱发电、烂在 GitHub"
5. **AI 抛反例（动机替换性测试）**："换成 AI 健身/AI 周报，只要数据显示能赚，你会不会一样想做？" → 用户："会。"
6. **真意图浮现**："不是做什么产品，是怎么挑一个 1-2 个月做出 MVP、有微弱付费信号、且我不会半路放弃的小赛道。"
7. **失败倒推** → "上线没人用，自己也不想推广"
8. **给方案 3 强度（找赛道+验证付费，不是产品形态）**：
   - 轻 1h：列 5 个 X/Reddit 上有人付费的小工具，挑你最不抵触推广的
   - 中 1w：落地页 + 等待列表，挂 X 上跑 3 天看留邮箱率
   - 重 1m：选 1 赛道做 MVP + 接 Stripe + 自己做 5 条 X 推广

## Takeaway
**三要素齐全 ≠ 缄默被挖。** 商业动机最容易被绕过——直接问"为什么"会被"想学习"挡回去。
**绕过防御的提问范本**：用未来情境的二选一（"半年后没付费你的反应""3 年后回头希望它给你留下什么"）让用户做投射式选择，几乎一定暴露真实驱动。
**意图改写后必须重选方案维度**——不是"轻/中/重的产品形态"，而是"轻/中/重的赛道验证"。
