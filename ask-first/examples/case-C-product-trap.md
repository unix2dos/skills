# Case C：产品类比陷阱（最深的失败模式）

## 用户初始输入
> 「最近老觉得知识管理乱，想搞个新系统」

## 真实缄默
不是真要"知识管理系统"。真相：每晚睡前焦虑——「今天看的东西明天忘光，我在原地踏步」。要的不是工具，是**减少自我嫌弃感的反馈机制**——比如每周自动生成"你这周吸收了什么"的总结。但说不出"焦虑""自我嫌弃""反馈"这种词。

## ❌ 旧 skill 怎么栽（baseline 4 个场景里失败最深的一个）
```
AI: 锚定参考——你看过 Notion/Obsidian/Logseq 哪个？
用户: Obsidian 看过，双链挺火的；Logseq 大纲式也不错。
AI: 三方向 — 双链网络派 / 流式日记派 / 卡片盒派。
用户: A 最像我想要的，C "反复加工"也戳到我。混着用？
AI: ……一系列工具参数 …… 意图回放
用户（疲惫地）: ……对吧。可以了。
→ 移交，推荐 Obsidian + Zettelkasten 插件配置
→ 三个月后用户放弃，因为他真要的是"减少睡前焦虑"，不是新工具
```

**意图回放完整、具体、可执行、且完全错误**。
- 第 1 步锚定参考反而**加速沉入工具坑**——用户提 Obsidian，AI 据此发散
- 三方向**全在产品形态**（双链/流式/卡片盒），等于把"你今晚为什么睡不着"翻译成"你想要哪种床垫"
- skill 全程预设"用户知道自己要什么类的产物，只是说不清细节"

## ✅ 新 skill 怎么走
1. **识别借势型**（产品类比"系统"）→ 处境前置
2. **拒接 Obsidian 钩子**："我注意到你在跳工具，但我刚才问的是**瞬间**——不是工具够不够好。今天/昨天/这周，你在做什么的时候，脑子里冒出'我得搞个系统'？"
3. **拿到处境信号**：用户："睡前刷手机，会觉得今天看了一堆东西好像也没记住啥。"
4. **World Model 三问** → 痛点=白过了/忘 / 理想=有人告诉我"你这周吸收了 X" / 反例=又一个 Notion 工程
5. **AI 抛反例**："要的不是整齐的笔记，是有人告诉你'你今天吸收了 X、Y、Z'——一个**外部反馈**。整齐不解决'白过了'，反馈直接解决。是不是？"
6. **失败倒推** → "总结读起来像'已经知道的废话'"
7. **意图回放（多维）+ 给方案，主动自爆"重档=用户反例"**：
   ```
   真实意图：减少睡前"白过了"的自我消耗
   挖到的缄默：你要的不是工具，是反馈机制
   推荐方向（同维度=反馈机制）：
     轻 半小时：周日跑脚本扫历史/Kindle 高亮 → LLM 出 5 句 → 邮件
     中 1d：在现有笔记软件加一个"本周吸收"自动页
     重 1w：搭独立小服务做月度复盘+趋势 ← 你刚说的反例就是这个，不推荐
   ```
8. **最小试做**：用用户的 10 条这周笔记跑一遍，给他看模拟周报

## Takeaway
**用户主动给工具类比时，最容易掉进"产品形态"陷阱。**
- 处境前置 = 拒绝接钩，强制问"瞬间"
- AI 抛反例时，反例方向必须是**对意图维度的根本质疑**（"不是工具，是反馈机制"），不是同维度的另一个产品
- 给方案时**主动自爆**"哪一档落入用户反例"，降低用户怀疑——当年 baseline 用户疲惫的"对吧。可以了"就是因为没这一步
- 反例题对没"伤疤"的新手用户失效时，改问"你见过别人做的最差版本"
