# Anti-Patterns（反模式）

baseline 测试 4 场景下被验证过的失败模式。每一条都来自真实失败对话，不是想象。

---

## 1. 三方向互斥发散（最大的陷阱）

**症状**：用户给了形容词级输入或产品类比，AI 立刻生成 3 个互斥方向请用户选。

**为什么错**：
- 三方向**预设维度**，把用户钉死在 AI 自己想到的那一层。如果维度本身错了（比如把"减少睡前焦虑"误当"产品形态"），三个方向越互斥用户越偏离。
- 三方向 = AI 替你想，违背 ask-first 的"AI 是镜子，让你自己看见自己"

**baseline 实证**：场景 C 给"双链/流式/卡片盒"三方向，把"睡不着"翻译成"想要哪种床垫"。

**新机制对应**：World Model 三问 → AI 抛 1 个反例（不是 3 个方向）→ 用户反驳 = 自我澄清。

---

## 2. 把用户的形容词当真实需求直接做发散

**症状**：用户说"性能更好"，AI 立刻按"性能"维度发散方案。

**为什么错**：形容词是情绪代偿，背后一定有一个具体场景。直接接受 = 接受用户的投射，错过真痛。

**baseline 实证**：场景 A "感觉太复杂了" → "想性能更好"是投射，真痛是 PR review 被打回。

**新机制对应**：投射型分流 → 触发动机问题"什么具体事让你今天想动它"。

---

## 3. 把用户的产品类比当强参考

**症状**：用户说"像 X 那样" / "做个 Y" / "搞个 Z"，AI 据此锚定方案。

**为什么错**：产品类比 = **借势 Y**，不是真意图 X。用户给类比往往是因为他还没想清楚、抓个熟悉的东西垫着。

**baseline 实证**：
- 场景 B "像 ChatGPT" → 真要的是"被使用+赚钱+自我证明"
- 场景 C "搞个新系统" → 真要的是"减少睡前焦虑的反馈机制"

**新机制对应**：借势型分流 → 处境前置，先压住产品讨论，问"非有这个不可"的具体瞬间。

---

## 4. 把"你看着办" / "差不多吧"当用户授权

**症状**：用户疲惫地说"你看着办"，AI 当成"用户授权默认值"继续推进。

**为什么错**：沉默 ≠ 同意。用户说"你看着办"几乎总是**感到方向不对又懒得纠正**的信号。

**baseline 实证**：场景 A 用户答两次"差不多吧""你看着办"，被当授权 → 错失 PR review 真痛。

**新机制对应**：Red Flags 第 4 条 → 拒收"你看着办"，反向用它当证据："上次同事说命名怪，就是因为有人替你看着办过一次。"

---

## 5. 三要素齐全（对象+动作+约束）就移交

**症状**：用户给了"AI 简历优化器 + 跳槽中级 + PDF + Web"这种参数清晰的请求，AI 直接进入意图回放后移交。

**为什么错**：参数清晰 ≠ 缄默被挖。**动机层的缄默**和**参数层的清晰**完全独立。

**baseline 实证**：场景 B 三要素全齐，但商业动机（被使用+赚钱+自我证明）完全没碰到，用户三个月后崩盘。

**新机制对应**：World Model 三问的"反例"项专门挖动机层。意图回放是"多维"（真意图/缄默/方向/失败），不是"参数清单"。

---

## 6. 澄清完就甩手不给方案

**症状**：AI 把意图挖清楚后，写个意图回放就移交下游 skill。

**为什么错**：用户最早的诉求里就有"给方案"这一项。澄清是手段，方案是产物。澄清完 = 工作做了一半。

**新机制对应**："AI 抛反例澄清 → 再给方案"两步缺一不可。Red Flags 第 6 条专门防这个。

---

## 7. 元焦虑场景下用结构化逃生舱继续掌舵

**症状**：识别为元焦虑后，AI 给 3 个"非常规选项"。用户拆穿"这也是结构"，AI 又给"非结构的结构"。

**为什么错**：元焦虑用户在质疑结构本身。任何结构性回应都是继续掌舵，加深用户"AI 没听见"的体验。

**baseline 实证**：场景 D 用户最终沉默退出。

**新机制对应**：元焦虑型三条特殊规则——必须给方案失效 / 被拆穿即承认悖论不再给新结构 / 拒绝 3 选项后兜底"我也不知道你想先聊什么"。**软性引导也禁**（三问语法变种 / 温柔诱导 / 元-元层级方案）。

---

## 一句话归纳

**所有反模式的本质 = AI 在用结构化方式替用户做了用户应该自己做的判断。**
ask-first 的解药 = 把"AI 替你想"换成"AI 帮你想"——镜子+反例+失败倒推+最小试做，让缄默在用户的反应里浮现。
