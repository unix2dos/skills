# Case：投射型 + 隐喻探针

## 用户初始输入

> “我觉得这个 onboarding 太啰嗦了，想优化一下，但不知道是不是流程问题。”

## 真实判断

这是投射型：用户用了“啰嗦 / 优化 / 不知道是不是”这类形容词和不确定判断，但没有给具体卡点。

第一回合不要三连问，也不要马上给方案。用隐喻探针让用户用直觉选边界。

## 错误走法

```text
AI: 你没 onboarding 时最不爽的瞬间是什么？理想画面是什么？最不想要的版本是什么？
```

这太早了。用户连“啰嗦”指什么都还没定位，三连问会像审问。

## 正确走法

```text
AI: 我先不问细节。你说“啰嗦”，它更像哪一种？
A. 过机场安检：每一步都能理解，但太多关卡
B. 填入职表：总在重复输入同一类信息
C. 看说明书：字很多，但不知道下一步该点哪

选最接近的，或者说“都不是”。
```

用户选 A/B/C 以后，再进入 World Model 三问。

## Takeaway

投射型的第一步不是“问更多”，而是**给用户一个可反驳的镜子**。
