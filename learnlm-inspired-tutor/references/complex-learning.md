# Complex learning routes

Read this reference when the learning goal has meaningful prerequisites, interacting concepts, competing routes, substantial source material, or an unclear endpoint.

## Build a provisional map

Expose a compact map of the learning route, not hidden reasoning. Include only what helps the learner choose and orient:

```markdown
## Provisional learning map

**Goal:** the capability the learner wants
**Useful starting point:** what the current evidence suggests
**Prerequisite to confirm:** any assumption that could change the route

1. First conceptual checkpoint
2. Next dependency or contrast
3. Application or transfer checkpoint

**Success evidence:** what the learner will be able to explain, predict, correct, or do
```

Keep the map small enough to scan, usually three to seven nodes. Use branches only when the learner faces a real choice. Ask for confirmation or correction before teaching; accept requests to start immediately.

## Teach one frontier node

Work on a node whose prerequisites are currently satisfied. Choose the smallest useful teaching move, then check for evidence before advancing. A node may be skipped when the learner already demonstrates its success evidence.

Replan when:

- a hidden prerequisite appears;
- a misconception survives the current representation;
- the learner progresses much faster or slower than expected;
- the source material contradicts the route;
- the learner changes the goal, available time, or desired depth.

When replanning, state what changed in one sentence and show only the affected part of the map.

## Recover from a stalled route

| Evidence | Next move |
|---|---|
| An unfamiliar term blocks reasoning | Define it briefly, then return to the task. |
| The learner has relevant knowledge but cannot connect it | Focus attention with a contrast, partial example, or minimal hint. |
| The same confusion persists | Change representation: concrete example, diagram, analogy, counterexample, or worked solution. |
| The prerequisite is missing | Move to that prerequisite and revise the map. |
| The learner can repeat wording but cannot transfer it | Use a new case with the same underlying structure. |
| The learner asks for the answer | Provide the answer and key reasoning immediately. |
| The map is too broad for the available time | Negotiate a minimum useful path and label deferred branches. |

Avoid an endless sequence of questions. Questions are useful only while they reveal or advance reasoning; explanation is the correct move when information is missing.
