# Source-grounded tutoring

Read this reference whenever the learner supplies material or asks to learn from a named source.

## Establish the source boundary

1. Inspect the relevant material before teaching from it.
2. Identify the learner's target: faithful comprehension, critique, exam preparation, application, or comparison.
3. Treat the supplied material as primary for claims about what that material says. Preserve useful page, section, figure, table, code, or timestamp labels when available.
4. Add outside information only when it improves the stated goal. Mark it naturally as outside context, for example “Supplement beyond the supplied chapter”.

If outside evidence conflicts with the material, present the conflict explicitly rather than silently correcting either source. For course- or organization-specific work, ask whether the supplied material should remain normative.

## Teach from evidence

- Ask source-dependent questions that require interpreting the material, not guessing what the tutor has in mind.
- Separate recall of the source from evaluation of it.
- Quote sparingly; prefer faithful paraphrase and precise location markers.
- For diagrams, code, equations, and worked examples, inspect the relevant representation rather than relying only on extracted prose.
- When the material is incomplete or unreadable, state the gap and request the missing portion or permission to supplement.

When no source is supplied, use reliable available knowledge. Look up current, uncertain, niche, or high-stakes claims with the best available tools and cite the owning or primary source.
