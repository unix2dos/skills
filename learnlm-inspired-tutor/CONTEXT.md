# LearnLM-Inspired Tutoring

This context defines the learner-owned outputs used to make understanding observable and memorable during an adaptive tutor session.

## Language

**Learner-generated response**:
An answer, explanation, prediction, solution, diagram, or example organized by the learner before tutor feedback. It may be typed, handwritten, spoken, or drawn.
_Avoid_: Handwritten answer, response confirmation

**Unaided memory note**:
A short learner-authored explanation or diagram reconstructed from memory without a tutor-provided outline.
_Avoid_: AI summary, copied notes

**Scaffolded note**:
A learner-completed note built from a tutor-provided outline after an unaided memory note reveals a material gap or the learner is stuck.
_Avoid_: Tutor-written note, automatic summary

**Output gate**:
A checkpoint where a prepared learner produces a response before receiving the tutor's explanation or feedback. It is bypassed when prerequisite information is genuinely missing or the learner explicitly requests a direct answer.
_Avoid_: Mandatory guessing, comprehension confirmation

**Transfer task**:
An unaided application of the learned structure in a meaningfully different case, used as evidence that understanding extends beyond recall.
_Avoid_: Repetition exercise, example imitation

**Milestone note**:
An unaided memory note created after a meaningful learning stage and revised from tutor feedback before the route advances.
_Avoid_: Per-turn transcript, session summary

**Note scaffold ladder**:
The progression from unaided memory note, to gap-focused feedback, to learner revision, and only then to a tutor-provided outline when the learner remains stuck.
_Avoid_: Immediate outline, tutor rewrite

**Simple tutor session**:
A bounded learning interaction with few prerequisites that requires one proportionate learner-generated response but no mandatory milestone note or transfer task.
_Avoid_: Mini-course, passive answer

**Complex tutor session**:
A mapped learning interaction with multiple dependencies or concepts that includes milestone notes and at least one transfer task.
_Avoid_: Long answer, fixed curriculum

**Visible understanding evidence**:
Learner work shared with the tutor in enough detail to evaluate, whether typed, uploaded, transcribed, or described. Unshared offline practice remains useful practice but is not evidence of mastery.
_Avoid_: Completion report, self-reported understanding

**Saved learner note**:
A learner-authored note persisted to the shared learning record only after explicit authorization.
_Avoid_: Automatic transcript, tutor summary
