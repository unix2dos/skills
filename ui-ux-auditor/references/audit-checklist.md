# 审计清单

逐项对照检查时加载此文件。每条项目标注判定标准。

## 视觉审计

### 色彩

- [ ] 是否定义了调色板变量/token（非硬编码 hex）？
- [ ] 主色是否在整个应用中一致使用？
- [ ] 语义色是否统一？（success/warning/error/info）
- [ ] 文字与背景对比度 ≥ 4.5:1（正文）/ 3:1（大文字）？
- [ ] 色彩使用总数 ≤ 5 主色 + 灰度层级？
- [ ] 悬停/激活状态是否用色彩变化（而非仅 `opacity`）？
- [ ] 是否存在色彩冲突（互补色并排产生视觉振动）？

### 排版

- [ ] 是否定义了字体栈（fallback 到系统字体）？
- [ ] 字号层级 ≤ 5 级？
- [ ] 层级步进是否遵循比例（如 1.25 或 1.333）？
- [ ] 正文行高 1.5-1.75？标题行高 1.2-1.4？
- [ ] 段落宽度 45-75 字符？
- [ ] 字重使用 ≤ 3 种（Regular / Medium / Bold）？
- [ ] 是否避免了全大写中文？
- [ ] 链接文字是否有明显的视觉区分？

### 间距

- [ ] 是否使用基准网格（4px 或 8px 倍数）？
- [ ] 间距变量是否系统化（token 而非魔法数字）？
- [ ] 卡片/容器 padding ≥ 16px？
- [ ] 列表项间距是否一致？
- [ ] 表单 label 与 input 间距 4-8px？
- [ ] 按钮内 padding 足够（最小 8px 12px）？

### 图标

- [ ] 图标风格是否统一（线性/填充不混用）？
- [ ] 图标大小是否规范化（16/20/24/32px）？
- [ ] 图标是否有明确的语义含义？
- [ ] 装饰性图标是否标记了 `aria-hidden`？

### 圆角与阴影

- [ ] 圆角值是否系统化（使用 token）？
- [ ] 同类组件圆角是否一致？
- [ ] 阴影是否分层级（sm/md/lg/xl）？
- [ ] 阴影颜色是否使用半透明黑而非纯灰？
- [ ] 是否避免了阴影+边框同时使用（视觉噪音）？

## 交互审计

### 按钮

- [ ] 按钮有 hover 状态？
- [ ] 按钮有 active（按下）状态？
- [ ] 按钮有 disabled 状态（视觉+交互都禁用）？
- [ ] 按钮有 loading 状态？
- [ ] 主按钮（Primary）在页面上只有一个？
- [ ] 按钮文案是否为动词（"提交"而非"确认按钮"）？
- [ ] 按钮最小触控区域 44×44px（移动端）？

### 表单

- [ ] 输入框有 focus 状态（明显的视觉变化）？
- [ ] 是否有即时验证反馈（不仅在提交时才校验）？
- [ ] 错误信息是否紧邻相关字段？
- [ ] 必填标记是否清晰？
- [ ] placeholder 是否只用作提示（而非替代 label）？
- [ ] 表单是否支持键盘导航（Tab 顺序）？

### 动效

- [ ] 过渡时长 200-300ms（不超过 500ms）？
- [ ] 使用 ease-out 或 cubic-bezier（非 linear）？
- [ ] 加载状态是否有反馈（skeleton/spinner/progress）？
- [ ] 页面切换是否有过渡（非硬切）？
- [ ] 动效是否可被 `prefers-reduced-motion` 禁用？
- [ ] 是否避免了让人分心的循环动画？

### 反馈

- [ ] 操作成功后是否有确认反馈（toast/消息）？
- [ ] 危险操作是否有二次确认？
- [ ] 空状态是否有引导（不是空白页）？
- [ ] 错误页面是否提供了恢复路径？

## 信息架构审计

### 导航

- [ ] 核心功能可在 3 次点击内到达？
- [ ] 当前位置是否清晰可见（高亮/面包屑）？
- [ ] 移动端导航是否可达（底部导航/汉堡菜单）？
- [ ] 导航项 ≤ 7 个（Miller 定律）？
- [ ] 导航标签是否用用户语言（非技术术语）？

### 内容组织

- [ ] 信息是否按重要性排列（F-pattern 或 Z-pattern）？
- [ ] 是否使用了渐进式披露（不一次展示所有选项）？
- [ ] 长列表是否有筛选/搜索/分页？
- [ ] 相关内容是否在空间上靠近（格式塔接近原则）？
- [ ] 标题/标签是否描述性足够强？

### 可访问性基础

- [ ] 所有图片有 alt 文本？
- [ ] 页面有合理的标题层级（h1→h2→h3，不跳级）？
- [ ] 交互元素可通过键盘操作？
- [ ] 焦点样式清晰可见？
- [ ] 颜色不是传达信息的唯一方式？

## 响应式设计审计

- [ ] 是否定义了断点系统（mobile/tablet/desktop）？
- [ ] 布局在 320px 宽度下是否正常（最小移动端）？
- [ ] 文字在小屏上是否仍然可读（≥ 14px）？
- [ ] 触控目标在移动端 ≥ 44×44px？
- [ ] 横向滚动是否被避免？
- [ ] 图片/视频是否自适应（不溢出容器）？
- [ ] 是否使用了相对单位（rem/em/%）而非固定 px？
